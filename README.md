# 2026 BUAA Phi Research Class (Fall)

Course repository for the BUAA Phi Research Class, Fall 2026.

Repo: https://github.com/taiyi98/2026-buaa-phi-research-class-fall

## How to contribute

This repository is **public**. Please submit work via Pull Request:

1. Fork this repository
2. Create a branch and push your code
3. Open a Pull Request against this repository

If you need direct push access, send your GitHub username to the course staff to be added as a Collaborator.

## Suggested layout

Use a per-student subdirectory (student ID or name) to avoid overwriting each other:

```text
students/
  2021XXXX/
    README.md
    code/
```
